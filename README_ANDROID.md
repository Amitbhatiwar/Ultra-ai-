# TryOnAI Ultra Pro — Android

Package: com.tryonai.ultrapro
Version: 2.0.0

This repository contains the Android WebView build of the TryOnAI Ultra Pro prototype.

The current build includes:
- AI Try-On UI flow
- Photo upload from Android
- AI Fashion Video UI
- Find & Compare marketplace UI
- AI Stylist / wedding looks
- Plans UI

Note: the current AI image/video generation and live marketplace pricing are prototype flows. Production AI requires backend/API integration.

GitHub Actions builds a debug APK automatically after pushes.
